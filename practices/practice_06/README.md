## 📝 Выводы для Pull Request (Conclusions)

В ходе выполнения работы были исследованы уязвимости как традиционного веб-стека (SQL-инъекции, IDOR/BOLA, XSS, подмена ролей), так и новые специфические векторы атак на системы с агентами искусственного интеллекта (Indirect Prompt Injection, Excessive Agency). 

Главный вывод: **языковая модель не может и не должна выступать единственным барьером безопасности системы**. Защита от prompt injection на уровне промпта всегда должна подкрепляться строгим разделением полномочий на уровне исполняющего кода (Tool RBAC), обязательной аутентификацией сессий и валидацией путей. Только комплексный подход Defense-in-Depth гарантирует сохранность персональных данных (152-ФЗ) и устойчивость бизнес-логики.
