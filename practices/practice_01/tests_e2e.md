# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный: авто-ревью PR | Подключён GitHub App, настроены секреты, бот в репозитории | Открыть PR с небольшим diff | В течение < 5 минут в PR появляются комментарии по строкам и сводка | Тайминги GitHub Events, логи бота |
| Негативный: отсутствует diff в API | Запущен API, клиент без поля diff | POST /api/reviews с {} | Ответ 422 с сообщением, без 5xx | HTTP логи и схема OpenAPI |
| Граничный: превышение лимита diff | Запущен API, тестовый клиент | POST /api/reviews с diff 128 KiB | Ответ 413/422; запись о превышении лимита | Метрики отказов, логи |
| Отказоустойчивость: 429 от LLM | Мок LLM с 2 первыми 429 | Открыть PR | Публикация комментариев после ретраев; нет 5xx для внешнего клиента | Логи попыток, интервалы backoff |

Проверка публикации комментариев и действий автора PR:
1. Бот публикует комментарии с идентификаторами находок.
2. Автор отвечает «fixed» на часть комментариев, пушит изменения.
3. Бот помечает закрытые замечания как resolved или не повторяет их в новой итерации.

## Как использовали AI

- Назначение запроса: зафиксировать сквозной сценарий «от webhook до комментариев», плюс негативные/граничные кейсы.
- Тип промпта: Master Prompt, сценарный формат.
- Ссылка на prompts.md: #P1-12
- Собственная верификация: сценарии соответствуют архитектуре и метрикам TtFR/SLAs; включены проверки публикации и корректной реакции на действия автора.
