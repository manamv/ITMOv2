## 1. Описание основного пользовательского сценария

* **Пользователь**: изучающий английский язык, желающий одновременно освоить слепую печать (десятипальцевый метод) и закрепить грамматические структуры языка.
* **Задача**:
  1. Выбрать уровень языка (A1–C2) и интересующую тему грамматики (например, *Past Simple vs Present Perfect* или тренировка слабых букв *Weak Keys*).
  2. Пройти интерактивный сеанс набора текста: виртуальная клавиатура подсвечивает нужные клавиши и зоны пальцев, робот-диктор озвучивает правильное произношение предложений, а по клику на незнакомое слово открывается перевод и транскрипция.
  3. Отправить результаты сеанса на сервер (или проверить перевод фразы через AI-анализатор грамматики) без риска повторного запроса (double-submit protection).
  4. Получить экран итоговой статистики: скорость (WPM), точность (%), список допущенных опечаток, обновление тепловой карты клавиатуры (Heatmap) и автоматическое сохранение трудных слов в личный словарь.
* **Результат**: пользователь видит измеримый прогресс скорости и точности, видит свои слабые клавиши и закрепляет правильную грамматику.

## 2. Использованные AI-инструменты и промпты

### Промпт 1: Концепт и дизайн-система (v0 / AI UI Generator)
```text
Role: Senior UI/UX Designer & Frontend Architect.
Goal: Design an ultra-sleek, modern dark-mode web application called "LinguaType" for blind touch-typing practice combined with English grammar mastery (levels A1-C2).
Aesthetics: Cyber-minimalism inspired by Monkeytype and Linear. Deep charcoal/slate background (#0d1117, #161b22), clean typography (JetBrains Mono for typing/code, Inter for UI), subtle glows.
Key UI Elements required:
1. Header: Logo, level selector (A1-C2 badges), streak counter, navigation tabs (Practice, Vocabulary, Statistics).
2. Active Typing Area: Large readable sentence with letter-by-letter status (typed, current with animated caret, remaining, errors highlighted in ruby-red).
3. Audio TTS button with wave animation.
4. Word translation popover showing phonetic IPA, Russian definition, and "Add to vocabulary" star.
5. Interactive QWERTY Virtual Keyboard:
   - Color-coded into 8 distinct finger zones (Left Pinky, Ring, Middle, Index; Right Index, Middle, Ring, Pinky; Thumbs for Space).
   - Real-time key highlight with glowing finger indicator.
6. Real-time metric pills: WPM, Accuracy %, Time left.
```

### Промпт 2: Генерация обязательных состояний интерфейса
```text
Generate complete UI layouts for all 5 mandatory states of the core scenario:
1. Default / Empty State: Level picker, grammar topic cards, weak-keys recommendation banner, empty stats placeholder when no history exists.
2. Active Input State: Typing in progress, live caret, keyboard finger highlight active, instant word translation tooltip open.
3. Loading State: Skeleton cards for lessons, pulsing progress bar, "AI analyzing grammar..." spinner.
4. Success / Result State: Large WPM display, Accuracy circle, mistake review list, keyboard heatmap preview, "Next Exercise" button.
5. Error State: Network disconnection banner, descriptive error message, "Try again" retry button with focus outline.
```

## 3. Что предложил AI vs Что было доработано вручную

| Компонент / Экран | Предложение AI | Ручная доработка и улучшение |
|---|---|---|
| **Виртуальная клавиатура** | Стандартная плоская клавиатура с подсветкой только нажатой кнопки. | Добавлена **система 8 цветовых зон пальцев** с подсказкой названия пальца над клавиатурой (например: *«Левый указательный палец»*), что критично для методики слепой печати. |
| **Озвучка (TTS)** | Предложено использовать сторонний платный API (ElevenLabs). | Интегрирован **нативный Web Speech API** с fallback на аудиозаписи носителей языка из Dictionary API, что обеспечивает нулевую задержку, бесплатность и работу оффлайн. |
| **Словарь и адаптивность** | Простой список слов в модалке. | Реализован **автоматический трекинг слабых клавиш (Weak Keys)**: система запоминает опечатки, строит тепловую карту (Heatmap) и генерирует тренировки с упором на проблемные буквы. |
| **Доступность (a11y)** | Красивые кастомные `div`-кнопки без ARIA и фокусов. | Переведено на семантические теги (`<button>`, `<label>`), добавлены четкие кольца фокуса `focus-visible:ring-2`, поддержка управления целиком с клавиатуры (Tab, Enter, Space, Escape для паузы). |
| **Защита от повторной отправки** | Обычная кнопка "Отправить" с обработчиком `onClick`. | Реализован строгий флаг `isSubmitting`, атрибут `disabled` и блокировка повторного нажатия Enter во время ожидания ответа сервера. |
| **Режим набора и эргономика** | Блокировка ввода на месте опечатки, смешанный регистр и знаки препинания, тексты разной длины. | 1) Добавлен **высокоточный секундомер предложений** (`MM:SS.s`).<br>2) Тексты стандартизированы **строго по 3 строки в высоту** (~150 символов), исключены заглавные буквы и пунктуация для фокусировки на непрерывном слепом наборе.<br>3) **Мягкое продвижение на опечатках:** неверная буква загорается ярко-красным, печать идёт дальше, а пользователь самостоятельно стирает ошибки клавишей `Backspace ⌫` для завершения предложения.<br>4) Исправлен вертикальный клиппинг нижней строки с запасом под нижние выносные элементы букв (p, y, g, q, j). |
| **Визуализация пальцев (Blind Typing)** | Отсутствовало изображение рук. | Разработан **анатомический визуализатор рук поверх клавиатуры (`BlindTypingKeyboard`)**: полупрозрачные темные силуэты рук лежат в исходной позиции (Home Row: `asdf` / `jkl;`), активная клавиша подсвечивается ярко-белым цветом, а соответствующий палец плавно вытягивается и нажимает на неё (1:1 соответствие эталону `blindtyping.com/ru/practice`). Сохранён переключатель в изометрический 3D-вид (`Keyboard3D`). |
| **Лидерборд (Соревновательность)** | Отсутствовал рейтинг пользователей. | Разработан **полноценный Лидерборд** (`LeaderboardView`): подиум топ-3 чемпионов (золото, серебро, бронза), фильтрация по уровням, таблица всех участников, форма сохранения рекорда с защитой от повторного нажатия и REST API (`/api/leaderboard`). |
| **Слепой ввод на слух (Диктант)** | Текст всегда был открыт перед глазами. | Добавлена **кнопка скрытия текста `[👁 Текст: СКРЫТ/ВИДЕН]`**: предстоящие буквы маскируются точками (`•`), вынуждая пользователя на слух определять слова и вводить их по памяти. Синхронизировано со скоростью озвучки и режимом опережающего произношения по словам. |
| **Музыкальные клипы & Разбор грамматики** | Отсутствовала связь с популярным медиа-контентом. | Реализован **отдельный режим «Клипы & Песни» (`MusicClipsView`)**: видеоплеер с клипами (Queen, Coldplay, The Beatles), синхронизированные субтитры с **автопрокруткой караоке** к текущей фразе и **пословной подсветкой в такт пению**, две вкладки анализа (разбор грамматических правил + **глубокий разбор смысла и культурного контекста от AI**), а также кнопка мгновенного старта слепой печати песни. |
| **Проверочные квизы по грамматике** | Прямой переход к финальному скорборду сразу после набора. | Добавлен **интерактивный квиз (`TopicQuizView`)** после полного прохождения темы: вопросы на выбор правильной формы слова, моментальная обратная связь с объяснением правила от AI, подсчёт баллов и возможность пропуска. |
| **Интерактивный перевод слов** | Статичные плашки со словами снизу текста, отвлекающие от печати. | Заменено на **нативный перевод по выделению курсором мыши** непосредственно в основном окне набора текста: выделение слова мгновенно вызывает плавающий всплывающий переводчик `WordPopover` с IPA-транскрипцией и озвучкой, устранен лишний визуальный шум снизу. |
| **Адаптивная верстка экрана набора** | На некоторых экранах появлялась вертикальная полоса прокрутки. | Реализована **строгая компоновка без скролла** (`h-[calc(100vh-5.5rem)] overflow-hidden`, высота клавиатуры с силуэтами ограничена `max-h-[240px]`), все элементы (статистика, таймер, текст, клавиатура) полностью умещаются в видимую область экрана на любом разрешении. |

## 4. Эволюция дизайна (v1 → v2) и синхронизация макета

После первичной реализации по базовому макету было проведено пользовательское ревью интерфейса, по итогам которого дизайн и UX были существенно переработаны, а локальный макет [`design/mockup.html`](./mockup.html) полностью обновлён в соответствии с шагом 4 задания (*«если решение изменилось, обновите макет»*):

| Область | Проблема в v1 (по итогам ревью) | Улучшение в v2 (реализовано и отражено в макете) |
|---|---|---|
| **Главное меню** | Сплошная сетка однотипных карточек, перегружающая взгляд; лишний бейдж `AI PRO` в шапке. | Переработано в **Bento Command Dashboard**: hero-блок быстрого старта, живой SVG-график динамики WPM, кнопка случайной темы, группировка **16 тем (A1–C1)** по уровням с переключением «Сетка / Список». Убран бейдж `AI PRO`, добавлены контекстные кнопки `← Назад`. |
| **Визуализация рук и пальцев** | Плоские полупрозрачные силуэты без объёма и ориентиров. | Переделано в **cyber-glass анатомию** (`BlindTypingKeyboard.tsx`): световые рёбра, градиентное затухание запястий, цветовое свечение активного пальца по 8 зонам и тактильные риски `F` / `J`. |
| **Поток после печати** | Сразу после набора открывался тест, пользователь не видел статистику и не получал эмоциональной награды. | Изменён сценарий на **`Печать → Статистика + звук + лёгкие хлопушки → Тест`**. При новом рекорде WPM проигрывается фанфара и запускаются полноценные салюты (`ConfettiCelebration.tsx`), а также показывается **AI-разбор опечаток и биграмм** с кнопкой быстрого спринта восстановления. |
| **Звуки и квиз (64+ вопроса)** | Отсутствовали звуковые сигналы при опечатках и в тесте; при неверном ответе не объяснялось, почему выбранный вариант не подходит. | Добавлен мягкий звук опечатки (`playErrorTap`), приятный аккорд завершения (`playCompletionChime`), разные звуки в тесте (`playQuizCorrect` / `playQuizWrong`), **двойной разбор ошибки** (почему выбранный вариант неверен + почему правильный верен) и перевод слов по клику прямо внутри квиза. |
| **Караоке-синхронизация** | Текст отставал от видеоклипа (~20 сек) из-за несовпадения хронометража LRC и YouTube-ролика; маленькое окно разбора правил. | Таймкоды пересобраны строго под точные длительности клипов (`185s` Queen, `265s` Coldplay, `126s` Beatles) по базе `lrclib.net` + двойная 60-FPS синхронизация (`YT.Player` + `infoDelivery`), кликабельный перевод слов в тексте песни и расширенная панель разбора правил (`max-h-[560px]`). |
| **Архитектура и тесты** | Дублирование логики словаря и выделения слов; 15 базовых тестов. | Вынесены чистые модули (`utils/dictionary.ts`, `hooks/useWordSelection.ts`, `data/quizBanks.ts`, `utils/weakKeys.ts`); тестовое покрытие расширено до **56 автоматических тестов** (включая E2E `TYPING → RESULT → QUIZ → TOPICS`, двойной разбор ошибок, дизайн-систему, каталог песен, квиз и 3D-карточки). |
| **Эволюция v3 (Design Polish & Scale)** | Фиксированная тёмная тема, лента из 3 клипов, плоский список слов, 10 наград. | Добавлены **Theme Studio (5 тем, включая светлую)**, **Zen Focus Mode**, **обложки YouTube + эквалайзер + Ambient Mood** на **14 треков (A2–C1)**, **Ритм-печать и Диктант (авто-пауза)**, **Словарь песни с переводом контекста**, **Тест на понимание песни + рекорды**, **смысловые группы + 3D-карточки (Flashcards)** в словаре, **интерактивная QWERTY Heatmap** с тултипами, **18 наград**, **плашка Caps Lock / раскладки** и **704+ мгновенных переводов слов**. |
