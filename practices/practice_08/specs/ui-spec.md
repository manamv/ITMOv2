# UI Specification (Команда Frontend / UI)

* **Фреймворк:** Spec-Kit (SDD)
* **Проект:** LinguaType (Практика 8)
* **Статус:** `APPROVED`

---

## 1. Концепция и дизайн-система

Интерфейс построен в эстетике **Cyber-Minimalism** с использованием библиотеки компонентов **shadcn/ui** и **Tailwind CSS v4**.

### 1.1. Цветовая палитра и токены
* **Фон страницы:** `#0b0f17` (глубокий сланцевый / Deep Slate).
* **Фон карточек:** `#131923` с границей `#202b3c`.
* **Основной акцент (Success/Active):** Изумрудный `#10b981` (Emerald).
* **Вторичный акцент:** Циан `#06b6d4` (Cyan) для точности и подсказок.
* **Ошибки и предупреждения:** Рубиновый `#f43f5e` (Rose) и янтарный `#f59e0b` (Amber).
* **Типографика:**
  * Текст набора и клавиатура: `JetBrains Mono`, `ui-monospace` (моноширинный шрифт исключает визуальный джиттер каретки).
  * Интерфейс и навигация: `Inter`, `system-ui`.

## 2. Спецификация виртуальной клавиатуры и зон пальцев

Клавиатура разделена на **8 цветовых зон для слепой печати** десятипальцевым методом:

| Зона пальца | Клавиши QWERTY | Цветовой класс |
|---|---|---|
| **Левый мизинец** | `` ` ``, `1`, `Tab`, `Q`, `Caps`, `A`, `Shift`, `Z` | `finger-pinky-l` (Rose-400) |
| **Левый безымянный** | `2`, `W`, `S`, `X` | `finger-ring-l` (Orange-400) |
| **Левый средний** | `3`, `E`, `D`, `C` | `finger-mid-l` (Yellow-400) |
| **Левый указательный** | `4`, `5`, `R`, `T`, `F`, `G`, `V`, `B` | `finger-index-l` (Emerald-400) |
| **Правый указательный** | `6`, `7`, `Y`, `U`, `H`, `J`, `N`, `M` | `finger-index-r` (Cyan-400) |
| **Правый средний** | `8`, `I`, `K`, `,` | `finger-mid-r` (Blue-400) |
| **Правый безымянный** | `9`, `O`, `L`, `.` | `finger-ring-r` (Purple-400) |
| **Правый мизинец** | `0`, `-`, `=`, `P`, `[`, `]`, `;`, `'`, `/`, `Enter`, `Backspace` | `finger-pinky-r` (Pink-400) |
| **Большие пальцы** | `Space` (Пробел) | `finger-thumb` (Slate-400) |

### Динамическое поведение клавиш:
* **Активная клавиша:** пульсирует неоновым изумрудным свечением (`key-pulse-active`).
* **Подсказка пальца:** над клавиатурой динамически отображается бейдж: `Символ: A ← Левый мизинец`.
* **Режим Heatmap:** клавиши окрашиваются в зависимости от процента ошибок ($>25\%$ — красный, $10-25\%$ — желтый, $<10\%$ — зеленый).

### 2.1. Интерактивная визуализация рук и пальцев (`HandsVisualizer`)
* Под клавиатурой отображаются две руки (Левая и Правая) с 10 пальцами, расположенными в исходной позиции (Home row: `a s d f` слева, `j k l ;` справа, большие пальцы на пробеле).
* **Анимация активного пальца:**
  * Палец поднимается вверх (`-translate-y-2.5`), подсвечивается полным цветом своей зоны и неоновым свечением (`shadow-[0_0_20px]`).
  * На подушечке пальца отображается анимированный бейдж с текущей целевой клавишей (например, `[r]`, `[␣]` или `[⌫]`).
  * Сверху динамически выводится статусная плашка: `Левая рука: Указательный → [r]`.

## 3. Спецификация обязательных состояний интерфейса

1. **Default / Selection State:**
   * Список уровней (A1–C2).
   * Рекомендованная плашка AI-адаптивного режима.
   * Сетка тем с карточками упражнений.
2. **Active Input State:**
   * **Отображение предложений строго в 3 строчки в высоту:** контейнер `min-h-[8.4rem] leading-[2.6rem] pb-2` с моноширинным шрифтом и увеличенным межстрочным интервалом, исключающим обрезание хвостиков нижних букв (`g, j, p, q, y`). Все предложения выровнены по длине, исключены заглавные буквы и знаки препинания.
   * **Режим слепого набора на слух (Text Hiding Toggle):** кнопка `[👁 Текст: СКРЫТ/ВИДЕН]` позволяет скрыть предстоящие буквы (маскируются символами `•`), оставляя видимыми только пробелы и текущий курсор. Пользователь слушает аудио-произношение и угадывает буквы по памяти на слух.
   * **Анатомическая клавиатура с силуэтными руками (BlindTypingKeyboard):** плоская темная клавиатура со сглаженными клавишами. Руки отображаются в виде полупрозрачных анатомических силуэтов в позиции Home Row (`asdf` / `jkl;`). Целевая клавиша подсвечивается ярко-белым цветом с черным шрифтом, а соответствующий палец плавно вытягивается и нажимает на неё (полное визуальное соответствие эталону BlindTyping.com). Доступно переключение на изометрический 3D-вид.
   * **Секундомер предложений (Stopwatch):** в реальном времени измеряет время набора текущего предложения с точностью до десятых долей секунды (`MM:SS.s`), запускается по первому нажатию клавиши, сбрасывается при переходе к следующему предложению.
   * **Поведение при опечатках:** при неверном вводе символ подсвечивается **ярко-красным** (`text-rose-400 bg-rose-500/25 underline decoration-rose-500`), но курсор продвигается вперёд («печать идёт дальше»). Пользователь самостоятельно стирает опечатки клавишей `Backspace ⌫`. При наличии неисправленных ошибок в конце предложения отображается подсказка и подсвечивается клавиша Backspace на виртуальной клавиатуре.
   * Кликабельные слова открывают `WordPopover` с IPA транскрипцией и переводом.
   * Live-панель: Секундомер, WPM, Точность, Ошибки, Скорость озвучки (0.75x–1.5x) и режим «По словам».

2.1. **Музыкальные клипы & Разбор грамматики (MusicClipsView):**
   * Вкладка `🎵 Клипы & Песни` в главной навигации.
   * Карусель выбора треков: Queen («We Are the Champions»), Coldplay («The Scientist»), The Beatles («Yesterday»).
   * Встроенный видеоплеер клипа с потоком синхронизированных субтитров (с подсветкой активной строки и аудио-озвучкой по клику).
   * Панель «Разбор правил песни»: карточки с цитатами из трека, грамматическими тегами и объяснениями грамматических конструкций.
   * Кнопка перехода к слепой печати песни: мгновенно открывает `TypingEngine` с текстом трека без заглавных букв и знаков препинания.
3. **Loading State:**
   * Анимированный спиннер, статусная плашка «Синхронизация с сервером...», скелетон-индикатор.
4. **Success / Result State:**
   * Счётчик WPM, точности %, затраченного времени.
   * Список слабых клавиш сессии.
   * Кнопка перехода к следующему уроку с защитой от повторного нажатия.
5. **Error State:**
   * Баннер сбоя сети / недоступности API с кнопкой «Повторить попытку» (`onRetry`).

## 4. Требования доступности (Accessibility & a11y)

* Все интерактивные элементы доступны с клавиатуры (`Tab`, `Shift+Tab`, `Enter`, `Space`, `Escape`).
* Фокус строго виден на всех элементах: `focus-visible:ring-2 focus-visible:ring-emerald-400`.
* Поля ввода в формах снабжены семантическими тегами `<label htmlFor="...">` с `*` для обязательных полей.
* Модальные окна содержат атрибуты `role="dialog"`, `aria-modal="true"`, `aria-labelledby`.
