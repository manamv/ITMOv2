# Thematic Grocery Curator Skill

## 1. Назначение
Навык предназначен для интеллектуального формирования и валидации тематических продуктовых наборов и рационов на основе каталога продуктов (ВкусВилл / здоровое питание). Позволяет агенту учитывать диетические требования, бюджетные ограничения, исключать опасные аллергены и добиваться гармоничного баланса белков, жиров и углеводов.

## 2. Архитектурное устройство навыка
- `SKILL.md` (данный файл) — системные правила, алгоритм кураторства и чеклист.
- `rules/nutrition-guidelines.md` — стандарты макронутриентов, целевые коридоры КБЖУ для разных тем (Студенческий, Кето, ПП, Без сахара).
- `scripts/validate_bundle.py` — содержательный модуль автоматизации для проверки сбалансированности продуктовых подборок и исключения аллергенов.

## 3. Процедура формирования подборки
1. **Сбор требований:** Тема рациона, целевой бюджет (руб), нежелательные ингредиенты / аллергены, суточный коридор калорий.
2. **Фильтрация на этапе каталога:**
   - Исключение всех позиций, содержащих указанные аллергены (`lactose`, `nuts`, `gluten`, `seafood`).
   - Отбор товаров с соответствующими тегами (`keto`, `budget`, `sugar_free`, `high_protein`).
3. **Оптимизация корзины:**
   - Подбор 3-6 позиций с суммарной стоимостью <= заданному бюджету.
   - Проверка баланса макронутриентов через автоматизированный скрипт `scripts/validate_bundle.py`.
4. **Формирование обоснования:** Краткое пояснение пользователю, почему именно эти продукты включены в набор.

## 4. Автоматизация проверки (Automation Script)
Для запуска автоматической валидации любого набора продуктов используется:
```bash
python .opencode/skills/thematic-grocery-curator/scripts/validate_bundle.py --bundle-json "<JSON_STRING>"
```
Скрипт возвращает статус `BALANCED` / `UNBALANCED`, индекс пищевой ценности и выявленные несоответствия.
