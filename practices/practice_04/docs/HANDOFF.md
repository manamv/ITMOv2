# HANDOFF: Передача контекста и состояние проекта VkusMart

## 1. Итоговый статус проекта
- **Фича A (Входная валидация & Фильтрация аллергенов):** Завершена и протестирована.
- **Фича B (Динамические скидки, Анализ БЖУ & Graceful Fallback):** Реализована в изолированном `git worktree`, проверена независимым QA-субагентом `@tester` (вердикт PASS) и смерджена в основную ветку через `git merge --ff-only`.
- **Сквозное тестирование:** 25/25 тестов пройдены успешно (exit code: 0).

## 2. Архитектурная карта компонентов
- `AGENTS.md` — глобальные правила и ограничения для агентов.
- `docs/requirements.md` — функциональные и нефункциональные требования.
- `docs/style-guide.md` — стандарты кода и правила строгой валидации.
- `.opencode/plugins/check-after-edit.js` — хук автопроверки `execute.after` для OpenCode 2.0.20.
- `.opencode/skills/thematic-grocery-curator/` — куратор продуктовых подборок и скрипт автоматизации `validate_bundle.py`.
- `mcp_server/server.py` — сервер протокола MCP (JSON-RPC 2.0) с тремя полезными инструментами.
- `opencode.json` — конфигурация MCP серверов (vkusmart-mcp, context7).
- `app/` — веб-сервис, каталог продуктов ВкусВилл, сервисный слой и SPA-фронтенд с живой консолью MCP.
- `scripts/check.sh` / `scripts/check.py` — доверенный кроссплатформенный runner.
- `tests/` — тестовое покрытие (каталог, фичи A и B, MCP сервер с обработкой ошибок).
- `reflection.md` — инженерная рефлексия разработчика.
- `presentation.html` — интерактивная презентация для демонстрации на защите.

## 3. Команда проверки
```bash
python scripts/check.py
# или
sh scripts/check.sh
```
