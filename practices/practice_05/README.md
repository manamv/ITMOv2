# Практика 5: SDD в Brownfield (Две команды — одна фича)

Данный проект выполнен в рамках Практики 5 по курсу «Вайб-кодинг / AI-агенты».  
В качестве основы взят brownfield-проект **VkusMart** из Практики 4. Ветка `practice_5` отведена непосредственно от ветки `practice_4`.

## 🚀 Быстрый старт

### 1. Запуск тестов (Pytest)
```bash
# Из папки practices:
python -m pytest practice_05/tests -v
```
*Результат: 38 тестов успешно пройдено.*

### 2. Запуск сквозного E2E-теста API
```bash
python practice_05/scripts/test_favorites_e2e.py
```
*Поднимает тестовый HTTP сервер и проверяет все 9 сценариев взаимодействия и ошибок.*

### 3. Запуск веб-приложения
```bash
python -m practice_05.app.server 8000
```
Откройте в браузере: `http://localhost:8000/`

## 📊 Ключевые решения согласования контракта

1. **`snake_case`:** UI перешёл с `productId` на `product_id`.
2. **Идемпотентный `POST`:** Повторное добавление товара возвращает `200 OK` (`already_exists: true`), что спасает от багов при double-click.
3. **Обогащенный DTO:** Сервер возвращает полную информацию о товаре + агрегаты (`total_price`, `total_calories`), устраняя рассинхронизацию цен.
4. **Атомарный перенос в корзину:** Эндпоинт `POST /api/favorites/move-to-cart` переносит товары и очищает список в единой транзакции.
