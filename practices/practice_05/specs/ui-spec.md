## 1. Концепция и цели
Обеспечить интуитивно понятное, быстрое и отказоустойчивое взаимодействие пользователя со списком избранных товаров VkusMart. Спецификация полностью согласована с контрактом `specs/contract.md`.

## 2. Компоненты интерфейса

### 2.1. Кнопка «Избранное» на карточках товаров
* **Селектор:** `.btn-fav[data-product-id]`
* **Состояния:**
  * **Неактивно:** класс `.btn-fav`, иконка `♡` (контурная). Подсказка `title="Добавить в избранное"`.
  * **Активно:** класс `.btn-fav.active`, иконка `❤️` (залитая). Подсказка `title="Удалить из избранного"`.
  * **В процессе запроса:** класс `.is-pending`, курсор `wait`, блокировка от повторных кликов до ответа сервера.
* **Логика клика:**
  * Если `!active`: отправка `POST /api/favorites` с `{"product_id": id}`.
    * При ответе `200 OK` (независимо от того, `added` или `exists`): выставить `.active`, обновить счетчик в шапке значением `total_count`, показать toast «Товар добавлен в избранное».
  * Если `active`: отправка `DELETE /api/favorites` (или `POST /api/favorites/remove`) с `{"product_id": id}`.
    * При ответе `200 OK`: снять класс `.active`, обновить счетчик в шапке значением `total_count`, показать toast «Товар удален из избранного».
  * При ошибке (404, 500, Network Error): вернуть состояние кнопки назад, показать toast с текстом ошибки из `response.message`.

### 2.2. Кнопка и бейдж в навигационной панели
* **Селектор:** `#nav-favorites-btn`
* **Разметка:**
  ```html
  <button id="nav-favorites-btn" class="nav-fav-btn" title="Открыть список избранного">
    <span class="icon">❤️</span>
    <span class="label">Избранное</span>
    <span id="fav-badge" class="badge">0</span>
  </button>
  ```
* **Поведение:**
  * Если `total_count == 0`: бейдж отображает `0` (или скрыт классном `.badge-empty`).
  * При изменении количества: анимация пульсации бейджа (`pulse`).
  * Клик вызывает `openFavoritesModal()`.

### 2.3. Модальное окно избранного
* **Селектор:** `#favorites-modal`
* **Элементы:**
  * **Шапка:** Заголовок «Избранное» + крестик закрытия.
  * **Сводка:** Информационный блок с количеством товаров, суммарной стоимостью и калорийностью:
    * `X товаров · Сумма: Y ₽ · Калории: Z ккал`
  * **Список товаров (`#favorites-items`):**
    * Каждая строка отображает: мини-название, категорию, белки/жиры/углеводы, вес, цену.
    * Кнопка быстрой покупки: «В корзину».
    * Кнопка удаления: иконка крестика.
  * **Кнопка пакетного переноса:**
    * `#move-fav-to-cart-btn`: Текст «Перенести всё в корзину».
    * При клике отправляет `POST /api/favorites/move-to-cart` с `{"clear_favorites": true}`.
    * По завершении: модалка переходит в пустое состояние, обновляется общая корзина VkusMart, показывается toast «Все товары перенесены в корзину!».
  * **Кнопка очистки:**
    * `#clear-fav-btn`: Текст «Очистить список». Отправляет `POST /api/favorites/clear`.
  * **Пустое состояние (`#favorites-empty`):**
    * Если список пуст, кнопки «Перенести всё в корзину» и «Очистить» деактивируются (`disabled`), а вместо списка показывается баннер «В избранном пока ничего нет».

## 3. Обработка ошибок в UI

1. **Товар не найден (404):**
   * Вывести toast: `«Товар не найден в каталоге»`.
   * Деактивировать кнопку на карточке.
2. **Пустой перенос в корзину (400):**
   * Если пользователь попытался перенести пустой список — кнопка `disabled`. Если запрос отправлен напрямую — toast `«Список избранного пуст»`.
3. **Сетевой сбой:**
   * Автоматический откат оптимистичного изменения интерфейса и сообщение: `«Сетевая ошибка. Попробуйте снова»`.
