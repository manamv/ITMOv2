# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель:
  - Согласовать правила CASE.md с tests_* и context.md по лимиту diff и форматам OUT-1.
- Доступные входы:
  - Файлы из репозитория: CASE.md, context.md, tests_* и product_management.md.
- Разрешённые действия:
  - Читать файлы, сопоставлять значения, формулировать минимальный патч.
- Запрещённые действия:
  - Придумывать новые правила без evidence; менять tests_*; выходить за пределы репозитория.
- Максимальное число шагов:
  - 5
- Условие остановки и вопроса человеку:
  - Остановиться, если обнаружены дополнительные расхождения помимо лимита и OUT-1; задать вопрос об источнике истины.

## Запрос
Проведи шаги: 1) найди значения лимита в CASE.md/context.md/tests_*; 2) найди описания формата OUT-1; 3) предложи минимальный патч к CASE.md; 4) проверь согласованность grep'ом; 5) зафиксируй критерии приёма.
